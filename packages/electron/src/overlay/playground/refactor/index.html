UI panel refactor — proposals

Three directions for a comprehensive panel refactor. All three preserve today's draggable multiple sections and compact mode behaviour.
Hard constraints (kept): multiple sections visible at once · sections draggable to rearrange · compact mode collapses to board-only

IA collapse

7 sections → 6. Drop standalone Display (lives in top-bar menu). Merge Lichess into Tools.

Tabbed dense sections

Tuning (Engine/Anim/Filter) and Diagnostics (Image/FEN/Highlights/Timing) get internal tabs — kills the 12-slider scroll wall.

Top-bar menus

Sections show/hide, display toggles, and PV mode all live in dropdowns instead of competing icon-toggles.

Persistent status

Live FPS · turn · depth · mpv visible in the top bar without opening any section.

1 · Workshop

Refined card grid — closest to today's split-layout. Cards drag to rearrange, drop-zones on edges. Tuning/Diagnostics use internal tabs to hide the slider wall.

+ familiar · + lowest migration cost

2 · Stack

Single vertical column of stackable sections. Each section has a collapse-to-strip control so you can keep many sections "available" without spending vertical space.

+ tiny width · + great for narrow displays

3 · Workspace

Split-layout upgraded with tab-stacked leaves — drop-on-center stacks the section as a tab inside the target leaf instead of replacing it (à la VSCode editor groups).

+ power-user density · − bigger UX shift
